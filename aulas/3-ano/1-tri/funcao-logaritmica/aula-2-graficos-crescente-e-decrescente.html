Gráfico da função logarítmica: crescente e decrescente

Medir a altura de uma criança ao longo dos anos mostra uma curva que cresce cada vez mais devagar. É o jeito da função logarítmica: sobe (ou desce) cada vez menos.

a > 1: crescente 0 < a < 1: decrescente assíntota x = 0

Objetivos da aula

O que você vai saber fazer

Calcule pontos com x potência da base: para log2 x, use x = 12, 1, 2, 4 e obtenha y = −1, 0, 1, 2.

Para início de conversa

Um crescimento que desacelera

Uma mãe anotou a altura do filho: (1; 0,60), (2; 0,80), (3; 1,00), (4; 1,10), (5; 1,20) — idade em anos e altura em metros. A altura sempre aumenta, mas cada vez menos: é o jeito de uma função logarítmica crescente.

Exemplo resolvido

Comparar logaritmos

Compare log2 5 com log2 3 e log1÷2 5 com log1÷2 3.

1
Base 2 (crescente)
5 > 3 ⇒ log2 5 > log2 3.
2
Base 1/2 (decrescente)
5 > 3 ⇒ log1÷2 5 < log1÷2 3 (inverte).

Resultado

log2 5 > log2 3 e log1÷2 5 < log1÷2 3.

Exemplo resolvido

Deslocamento

Para g(x) = log2(x − 1) + 3, dê o domínio, a assíntota e o valor de g(2).

1
Domínio
x − 1 > 0 ⇒ x > 1.
2
Assíntota
x = 1 (o gráfico foi deslocado 1 unidade para a direita).
3
Valor
g(2) = log2 1 + 3 = 0 + 3 = 3.

Resultado

D = {x ∈ ℝ ∣ x > 1}, assíntota x = 1 e g(2) = 3.

Exemplo resolvido

Inequação logarítmica

Resolva log2 x > 3 e log1÷2 x > 3.

1
Primeira (crescente)
log2 x > 3 = log2 8 ⇒ x > 8.
2
Segunda (decrescente)
log1÷2 x > 3 = log1÷2(18) ⇒ a desigualdade inverte: x < 18.
3
Domínio
Em ambas, x > 0: segunda ⇒ 0 < x < 18.

Resultado

x > 8 e 0 < x < 18.

Cuidados

Onde o gráfico logarítmico engana

Confundir assíntotas

A assíntota da log é o eixo y (x = 0); a da exponencial é o eixo x.

Cruzar o eixo y

O gráfico nunca cruza o eixo y (não há f(0)); cruza o eixo x em (1, 0).

Inverter a desigualdade só às vezes

Em inequações, base < 1 inverte; base > 1 mantém.

Esquecer o domínio

Em log1÷2 x > 3, além de x < 1 ÷ 8 é preciso x > 0.
