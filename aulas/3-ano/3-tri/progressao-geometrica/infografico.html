Aula 79

Definição e razão

Sequência em que, a partir do 2º termo, cada termo é o produto do anterior por uma constante q (a razão).

Como calcular q

Divida qualquer termo (a partir do 2º) pelo seu antecedente: q = an+1 ÷ an

(2, 6, 18, 54, …) ⟹ q = 6÷2 = 3

Aula 79–81

Fórmula do termo geral

Permite encontrar qualquer termo sem escrever a sequência inteira.

Termo geral

an = a1 · qn−1

an = termo procurado · a1 = 1º termo · q = razão · n = posição

Ex.: dívida de R$115 que triplica; a1=345, q=3, n=5 → a5 = 345·3⁴ = R$ 27.945

Aulas 82–83

Soma dos termos de uma PG finita

Soma os n primeiros termos sem somá-los um a um.

Soma finita (q≠1)

Sn = a1(qn−1)q−1

Se q = 1: Sn = n · a1

Ex.: tabuleiro de xadrez — a1=1, q=2, n=64 → S64 = 2⁶⁴−1 ≈ 18,4 quintilhões de grãos

Aula 84 · Habilidade H21

Aplicações financeiras

Depósitos periódicos com juros compostos formam uma PG: cada depósito rende por um número diferente de períodos.

elementovalor
a1R · (1+i)
q(1+i)
nnº de depósitos

Ex.: R$100/mês, 1% a.m., 10 depósitos → a1=101, q=1,01, n=10 → S10 = R$ 1.056,46

No ENEM é assim

Dicas para a prova

  1. Procure palavras-chave como "dobra", "triplica", "cresce x% a cada período" — são sinais de PG.
  2. Identifique a1 (cuidado: às vezes o "valor inicial" do enunciado não é a1 — confira o índice certo).
  3. Escolha a fórmula certa: termo geral para "qual é o valor no instante n"; soma para "quanto se acumula até n".
  4. Em problemas financeiros, escreva sempre q = (1 + taxa) e confirme quantos períodos cada depósito rende.
