Aula 71

Definição

Uma sequência numérica é uma lista ordenada de números. A ordem importa: trocar a posição altera a sequência.

(a1, a2, a3, …, an, …)

Finita × infinita

Finita: (2, 4, 6, 8)  ·  Infinita: (1, 3, 5, 7, …)

Aulas 69 e 71

Como identificar um padrão

Compare termos consecutivos e observe o que se repete a cada passo.

  1. Calcule a diferença entre termos consecutivos (a2−a1, a3−a2, …).
  2. Se a diferença é sempre a mesma, a sequência é linear — forme an=kn+b.
  3. Se não for constante, calcule as diferenças das diferenças (2ª diferença): se ela for constante, a sequência é quadrática.
  4. Se a razão entre termos consecutivos é sempre a mesma (em vez da diferença), a sequência é exponencial.
  5. Confirme a fórmula testando-a com pelo menos dois valores conhecidos de n.
Aula 72

Termo geral linear

an = kn + b

k é a diferença constante. Exemplo: (14, 18, 22, 26, …) → diferença +4 → an=4n+10.

Aula 71

Termo geral quadrático

an = an² + bn + c

2ª diferença constante. Exemplo: (0, 3, 8, 15, 24, …) → an=n²−1.

Aulas 70 e 72

Termo geral exponencial

an = a1 · rn−1

Razão r constante. Exemplo: (3, 6, 12, 24, …) → an=3·2n−1.

ENEM 2021 · Questão 136

Recorrência escondida

φ² = φ+1. As potências φn na forma aφ+b escondem a sequência de Fibonacci nos coeficientes a e b.

φ⁶=8φ+5 ⟹ φ⁷=13φ+8

Truque

Cada coeficiente é a soma dos dois anteriores — assim como em toda a sequência de Fibonacci.

Dicas para resolver questões de ENEM

Como atacar uma questão de sequências

Leia 3 vezes

Texto de base, comando da questão e alternativas — nessa ordem.

Monte a tabela

Escreva os valores de n e an lado a lado antes de generalizar.

Calcule diferenças

Diferença constante = linear. 2ª diferença constante = quadrática.

Teste a fórmula

Substitua dois valores de n conhecidos antes de confiar na resposta.

Desconfie de armadilhas

Coeficiente igual ao expoente, ou "+expoente" direto na fórmula, raramente é correto.

Confira a posição

Cuidado com a diferença entre "etapa n" e "número de dobras/somas até n".

Crescimento linear

Sobe em passos iguais — reta.

Crescimento exponencial

Dispara depois de poucos termos — curva.
