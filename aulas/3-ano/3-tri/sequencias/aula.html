Para início de conversa

O que a casca do abacaxi, o girassol e os anéis da árvore têm em comum?

Dendrocronologia é o ramo da ciência que estuda a datação dos anéis de crescimento das plantas. Por meio dos padrões dos anéis, conseguimos determinar a idade das árvores e analisar outras características.

Já a casca de um abacaxi não organiza suas escamas de forma aleatória: há uma ordem clara em como cada camada cresce e se sobrepõe — um padrão que se repete e se transforma segundo uma regra.

No centro do girassol

As sementes crescem em espirais intercaladas — algumas no sentido horário, outras no anti-horário. Contando as espirais de cada sentido, os dois números quase sempre são termos consecutivos da sequência de Fibonacci, brotando em ângulos de aproximadamente 137,5° (o Ângulo de Ouro).

Em todos os casos, a natureza segue um padrão que se repete e se transforma de acordo com uma regra — exatamente o que chamamos de sequência numérica.

Quando enxergamos essa regra oculta, ganhamos a capacidade de prever exatamente a próxima etapa, sem precisar construí-la ou contá-la uma por uma.

Aula 71 · Teoria

O que é uma sequência numérica

Definição

Uma sequência numérica é uma lista ordenada de números. A ordem importa: mudar a posição de um número altera a sequência.

Finitas e infinitas

Finita: tem um número determinado de termos.
Exemplo: (2, 4, 6, 8).

Infinita: continua indefinidamente.
Exemplo: (1, 3, 5, 7, …).

Notação an

a1: primeiro termo · a2: segundo termo · an: termo geral (posição n)

(5, 10, 15, 20) ⟹ a1=5, a3=15

Aulas 71 e 72 · Teoria

Da lista de números à fórmula

A lei do termo geral (an) é uma regra matemática que calcula o valor do termo usando apenas a sua posição n.

Termo geral

an = 3n + 1

a1 = 3(1)+1 = 4  ·  a2 = 3(2)+1 = 7

Já (1, 4, 9, 16, 25, …) tem termo geral an = n².

Método das diferenças constantes

Sequência de assentos: (14, 18, 22, 26, …). Diferença sempre +4 → forma An = 4n + k.

Usando A1=14: 4(1)+k=14 ⟹ k=10 ⟹ An = 4n + 10.

Regra prática

Se a diferença entre termos consecutivos é sempre a mesma, a sequência é linear (an=kn+b). Se a diferença das diferenças (2ª diferença) é constante, a sequência é quadrática (an=an²+bn+c).

Atividade 2 · Qual é a regra?

Encontre a expressão geral

Observe a sequência (1, 4, 7, 10, …), onde n é a posição de cada termo. Qual é a regra geral?

Testando n=1 (esperado 1): apenas a alternativa A erra (n+3=4).

Testando n=2 (esperado 4): B dá 3 e D dá 5 — só C dá 4.

Logo, a regra geral é an = 3n − 2.

Canudos de refrigerante

Uma professora realizou uma atividade com seus alunos utilizando canudos de refrigerante para montar figuras, em que cada lado foi representado por um canudo. A quantidade de canudos (C) de cada figura depende da quantidade de quadrados (Q) que formam cada figura.

III310

Que expressão fornece a quantidade de canudos em função da quantidade de quadrados de cada figura?

1ª estratégia — padrão visual: o primeiro quadrado usa 4 canudos "fixos". A partir daí, um lado já existe, então cada novo quadrado soma apenas 3 canudos. Logo C = 3Q + 1.

2ª estratégia — teste de alternativas: para Q=1 (C=4), A, B e D funcionam, mas C erra (4·1−1=3). Para Q=2 (C=7), apenas B bate: 3·2+1=7.

Resposta: C = 3Q + 1.

Atividade 5 · No ENEM é assim (ENEM 2021 · Questão 136 · Prova Azul)

As potências da razão áurea

Um segmento de reta está dividido em duas partes na proporção áurea quando o todo está para uma das partes na mesma razão em que essa parte está para a outra. Essa constante de proporcionalidade é comumente representada pela letra grega φ, e seu valor é dado pela solução positiva da equação φ² = φ + 1.

Assim como a potência φ², as potências superiores de φ podem ser expressas da forma aφ + b, em que a e b são inteiros positivos, como apresentado no quadro.

ENEM 2021 · Resolvendo

Duas estratégias para chegar à resposta

1ª estratégia — padrão da sequência

Sequência dos valores de a: 1, 2, 3, 5, 8, …
1+2=3  ·  2+3=5  ·  3+5=8  ·  próximo: 5+8=13

Sequência dos valores de b: 1, 1, 2, 3, 5, …
1+1=2  ·  1+2=3  ·  2+3=5  ·  próximo: 3+5=8

Cada número é a soma dos dois anteriores — um Fibonacci escondido!

2ª estratégia — raciocínio algébrico

φ⁷ = φ⁶ · φ, e do quadro φ⁶ = 8φ + 5. Logo:

φ⁷ = (8φ+5)·φ = 8φ² + 5φ

Substituindo φ² = φ+1: φ⁷ = 8(φ+1) + 5φ = 8φ + 8 + 5φ

Resposta

φ⁷ = 13φ + 8

ENEM 2023 · Resolvendo

O método das diferenças sucessivas

Passo 1 — calcule as diferenças entre termos consecutivos:

5−1=4  ·  12−5=7  ·  22−12=10  ·  35−22=13  ·  51−35=16

A sequência de diferenças é 4, 7, 10, 13, 16 — e ela cresce sempre +3.

Passo 2 — continue o padrão das diferenças até a posição desejada:

próxima diferença (para P7): 16+3=19  ·  próxima diferença (para P8): 19+3=22

Passo 3 — some as diferenças aos termos anteriores:

P7 = 51+19 = 70  ·  P8 = 70+22 = 92

Resposta

O oitavo número pentagonal é 92.

Aulas 70 e 72 · Teoria

Quando o crescimento é multiplicativo

Nem toda sequência cresce por soma constante. Às vezes, cada termo é obtido multiplicando o anterior por um fator fixo — um crescimento exponencial.

Dobrando a cada passo

(3, 6, 12, 24, 48, …) ⟹ an = 3·2n−1

Metade a cada passo

(½, ¼, ⅛, …) ⟹ an = 2−n

Dica

Se a razão entre termos consecutivos (an+1/an) é sempre a mesma, a sequência é exponencial (geométrica) — não linear. Se a diferença é constante, é linear.

Atividade 6 · No ENEM é assim (ENEM 2024 · Questão 142 · Prova Azul)

Copiar, colar e a mensagem de emojis

Uma criança, utilizando um aplicativo, escreveu uma mensagem seguindo estas etapas: 1ª etapa — inseriu três figuras do tipo 🙂 no visor. 2ª etapa — copiou o que havia inserido e colou ao lado. 3ª etapa — copiou o que tinha no visor na 2ª etapa e colou ao lado. A criança seguiu copiando e colando, em cada etapa, o que tinha na etapa imediatamente anterior, até concluir a 20ª etapa.

Qual foi o total de figuras contidas na mensagem enviada?

1ª etapa: 3 figuras = 3·2⁰  ·  2ª etapa: 6 = 3·2¹  ·  3ª etapa: 12 = 3·2²  ·  4ª etapa: 24 = 3·2³

Padrão: na etapa n, o total é 3 · 2n−1.

Para n = 20: total = 3 · 220−1 = 3 × 2¹⁹.

Atividade 7 · Aplicações reais

Do mosaico ao anfiteatro

Copie os dados e resolva no caderno; depois confira a resolução.

Pavimentação sustentável

Blocos cinzas (C) ao redor de n blocos brancos: n=1→C=6, n=2→C=8 (+2), n=3→C=10 (+2).

Diferença constante = 2 ⟹ C(n) = 2n + b. Usando n=1: 2+b=6 ⟹ b=4.

C(n) = 2n + 4

Para 45 blocos brancos: C(45) = 2·45+4 = 94 blocos cinzas.

Anfiteatro universitário

Assentos por fila: (14, 18, 22, 26, …), diferença constante = 4.

An = 4n + k. Usando A1=14: 4+k=14 ⟹ k=10 ⟹ An = 4n + 10.

Para 78 pessoas: 4n+10=78 ⟹ 4n=68 ⟹ n=17.

A 17ª fila acomoda exatamente o grupo.

A ideia central

Toda sequência esconde uma regra. Encontrar essa regra — e escrevê-la como expressão algébrica do termo geral — é o que nos permite prever qualquer posição, mesmo a 100ª, sem contar um por um.

A régua que descreve o mundo
