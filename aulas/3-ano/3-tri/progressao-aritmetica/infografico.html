Aula 73

Definição

É uma sequência em que cada termo, a partir do 2º, é igual ao anterior somado a uma razão constante.

r = a2 − a1 = a3 − a2 = ...

Exemplo

(1, −7, −15, −23, ...) → r = −7 − 1 = −8

Aula 73

Classificação de uma P.A.

O sinal da razão define o comportamento da sequência.

crescenter > 0

(0, 1, 2, 3, ...)

decrescenter < 0

(−4, −7, −10, ...)

constanter = 0

(½, ½, ½, ...)

P.A. e função afim

an = r·(n−1) + a1

O crescimento é constante, como numa reta y = ax + b.

Aula 76

Soma dos termos

Sn = (a1+an)·n / 2

Pareia extremos equidistantes — a sacada de Gauss aos 10 anos.

Aula 78

Forma expandida

Sn = [2a1+(n−1)r]·n / 2

Use quando não conhece an diretamente.

Aula 76

Caso especial

Sn = n²

Soma dos n primeiros números ímpares (1, 3, 5, 7, ...).

Dicas para o ENEM

Armadilhas mais comuns

"mês seguinte"

Ache o mês em que a condição se cumpre e depois avance mais um passo — não pare cedo demais.

termos conhecidos ≠ a₁

Se souber dois termos quaisquer (ex.: a₃ e a₅), use aₖ = aⱼ + (k−j)·r para achar r sem precisar de a₁.

Sₙ leva a equação do 2º grau
