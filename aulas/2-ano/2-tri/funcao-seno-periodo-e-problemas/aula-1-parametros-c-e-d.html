Parâmetros c e d: período e deslocamento da senóide

No rádio AM, a onda varia de altura (amplitude); no FM, varia a frequência, isto é, o período. Em y = a + b · sen(cx + d), o parâmetro c controla o período e d desloca a onda para a esquerda ou para a direita.

período = 2π ÷ |c| deslocamento = −d ÷ c a, b, c, d
Conhecimentos prévios

AM e FM: amplitude e frequência

No rádio AM, a mensagem altera a amplitude da onda (parâmetro b). No FM, altera a frequência: a onda fica mais “apertada” ou mais “esticada”, isto é, muda o período (parâmetro c).

Duas ondas em 2π: cada uma tem comprimento π. É a fórmula 2π ÷ c = 2π ÷ 2 = π.

Objetivos da aula

O que você vai saber fazer

  • Calcular o período de y = a + b · sen(cx + d) por 2π|c|.
  • Interpretar d como deslocamento horizontal: o período começa em x = −d ÷ c.
  • Escrever e interpretar a lei completa a partir de um gráfico.

Dica

Para achar onde um período começa, resolva cx + d = 0; para achar onde termina, resolva cx + d = 2π.

Teoria · parâmetro c

Quanto maior c, mais curto o período

  • Em y = a + b · sen (cx + d): período p = 2π|c|.
  • c = 1: período 2π (a senóide-base). c = 2: período π (onda “apertada”). c = ½: período 4π (onda “esticada”).
  • c e o período são inversamente proporcionais.
  • c não altera a imagem (que depende só de a e b).

Teoria · parâmetro d

Deslocar a onda: o início do período

  • O parâmetro d translada o gráfico horizontalmente e muda onde um período começa.
  • O período começa onde cx + d = 0, isto é, em x = −dc.
  • d > 0: o gráfico vai para a esquerda. d < 0: vai para a direita.
  • Exemplo: y = sen (x − π2) começa em x = π2 (deslocada π ÷ 2 para a direita).

Período de uma função

Qual o período de f(x) = 3 · sen (4x)?

1
Parâmetros
a = 0, b = 3, c = 4 e d = 0.
2
Período
p = 2π4 = π2.

Resultado

O período é π2.

Exemplo resolvido passo a passo

Com c fracionário

Determine o período e a imagem de y = 2 · sen (x4).

1
Parâmetro c
c = 14 ⇒ período p = 2π ÷ 14 = 8π.
2
Imagem
a = 0 e |b| = 2: [−2, 2].

Resultado

Período 8π e imagem [−2, 2].

Deslocamento

Onde começa um período de y = sen (x + π3) e qual é o período?

1
Resolver cx + d = 0
x + π3 = 0 ⇒ x = −π3.
2
Período
c = 1 ⇒ 2π: o período vai de −π3 a 5π3.

Resultado

O período começa em −π3 (gráfico deslocado para a esquerda) e vale 2π.

Cuidados

Onde c e d enganam

Multiplicar em vez de dividir

O período é 2π ÷ |c|: dividir, nunca multiplicar.

Esquecer que d é dividido por c

O deslocamento é −d ÷ c, não −d.

Sinal do deslocamento

sen (x − π) vai para a direita; sen (x + π), para a esquerda.

Achar que c muda a imagem

A imagem só depende de a e b.
