A lotação do cinema

Pense na função que associa cada pessoa da sala à sua poltrona. Três cenas possíveis:

Mais poltronas que pessoas

Cada um na sua, mas sobram poltronas vazias.

Sala lotada, 1 por poltrona

Toda poltrona ocupada, ninguém divide.

Poltronas divididas

Todas ocupadas, e crianças dividem poltrona com um adulto.

Isso também é matemática

Cada cenário descreve uma propriedade diferente de uma função (pessoa → poltrona). Vamos formalizar isso — e antes, ver como escrever uma função que muda de regra dependendo do valor de x.

Aula 90 · Teoria

Função definida por mais de uma sentença

Algumas situações não seguem uma única fórmula — a regra muda conforme o intervalo de x.

No ENEM é assim (ENEM PPL 2020)

Uma corrida de táxi cobra bandeirada de R$ 4,50, que cobre até 200 m rodados; a partir daí, mais R$ 0,02 por metro.

f(d) = 4,50, se 0 ≤ d ≤ 200
f(d) = 4,50 + 0,02(d − 200), se d > 200

d em metros. Conferindo com o gabarito oficial: uma corrida de 600 m custa 4,50+0,02·400 = R$ 12,50.

Como calcular

Primeiro descubra em qual sentença o valor de x se encaixa — depois aplique só aquela fórmula.

Atividade 1 · No quadro, oral

Calcule a corrida

Usando f(d) = 4,50 (até 200 m) ou f(d) = 4,50 + 0,02(d−200) (acima de 200 m):

f(150) = ?

d=150 ≤ 200 → R$ 4,50

f(600) = ?

4,50+0,02(600−200)=4,50+8 → R$ 12,50

f(d) = 20,50. Qual d?

0,02(d−200)=16 → d−200=800 → d=1.000 m (1 km)

Aula 91 · Teoria

Resolvendo problemas com função por partes

No ENEM é assim (ENEM 2021)

Um imposto I sobre o preço R de um produto é calculado por faixas:

I = 0, se R ≤ 5.000
I = 0,10(R − 5.000), se 5.000 < R ≤ 10.000
I = 500 + 0,30(R − 10.000), se 10.000 < R ≤ 15.000

Qual o imposto de um produto de R$ 8.000?

8.000 está na 2ª faixa: I = 0,10·(8.000−5.000) = 0,10·3.000 = R$ 300,00

Conferindo os pontos-chave do gabarito: R=5.000→I=0; R=10.000→I=500; R=15.000→I=2.000.

Atividade 2 · Em duplas · No ENEM é assim (ENEM PPL 2010)

De trás para frente: quanto ela consumiu?

Entre 15 e 20 m³, a conta de água de um município segue C(m) = 15 + 2(m−15), com C em reais.

Uma família usou 18 m³. C(18) = ?

15+2(18−15)=15+6 → R$ 21,00

Uma moradora pagou R$ 19,00. Quantos m³ ela consumiu?

15+2(m−15)=19 → 2(m−15)=4 → m−15=2 → m = 17 m³ (gabarito oficial)

Isso é pensar ao contrário

Dado o resultado (a conta), você encontrou a entrada (o consumo) — essa é exatamente a ideia por trás da função inversa, que vem na Parte 2.

Aula 92 · Teoria

Função sobrejetora

f: A → B é sobrejetora quando todo elemento de B é imagem de pelo menos um elemento de A — ou seja, Im(f) = B.

Em outras palavras

Ninguém em B fica "de fora". O contradomínio inteiro é atingido.

Todo ponto de B recebe seta — nenhum sobra.

Aula 93 · Teoria

Função injetora

f: A → B é injetora quando elementos diferentes de A têm imagens diferentes em B.

x₁ ≠ x₂ ⟹ f(x₁) ≠ f(x₂)

Em outras palavras

Nenhum elemento de B recebe duas setas. Pode sobrar gente em B sem par.

Cada seta chega num ponto diferente de B.

Atividade 3 · No quadro

Verdadeiro ou falso?

Classifique cada afirmação sobre f: A → B.

Se todo elemento de B tem pelo menos uma seta chegando, f é sobrejetora.
Se dois elementos de A têm a mesma imagem em B, f ainda pode ser injetora.
Uma função injetora pode deixar elementos de B sem seta.
Aula 94 · Teoria

Função bijetora

Se f é injetora e sobrejetora ao mesmo tempo, ela é bijetora.

injetora + sobrejetora = bijetora

Por que importa

Só funções bijetoras têm inversa em todo o domínio — vamos usar isso na próxima aula sobre função inversa.

Cada elemento de A com seu par único em B — e ninguém sobra.

Atividade 6 · Em duplas

Restringindo o domínio de uma parábola

f(x) = x² − 6x + 5, com domínio restrito a A = [3, +∞[. Vértice em (3, −4), raízes em 1 e 5. (Lembrete: no vértice a parábola muda de decrescente para crescente — por isso restringir o domínio a x ≥ 3 evita repetir imagens.)

( ) O contradomínio B = [−4, +∞[ garante que f seja sobrejetora.

( ) f é injetora em A, pois é estritamente crescente para x ≥ 3.

V — para y < −4 não há x que o gere; para y ≥ −4, sempre há.

V — restrito a x ≥ 3 a parábola só cresce, então valores de x diferentes dão imagens diferentes.

Síntese

As três propriedades, lado a lado

Injetora

imagens sempre diferentes — pode sobrar gente em B

Sobrejetora

todo B é atingido — pode repetir imagem

Bijetora

as duas ao mesmo tempo — combinação perfeita

E a função por partes?

Uma função por partes também pode ser classificada com essas mesmas propriedades — basta analisar o comportamento de cada sentença no seu intervalo.
