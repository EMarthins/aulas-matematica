PROBLEMA 4

Resolva: 3x+2 = 81

81 = 3⁴, então x+2 = 4 ⟹ x = 2.

PROBLEMA 5

Resolva: 4x − 5·2x + 4 = 0

Fazendo y = 2x: y² − 5y + 4 = 0 ⟹ y = 1 ou y = 4.

2x = 1 = 2⁰ ⟹ x = 0.    2x = 4 = 2² ⟹ x = 2.

PROBLEMA 6

Um capital de R$ 2.000,00 é aplicado a juros compostos de 10% ao ano. Qual o montante após 2 anos?

M = 2000 · (1,10)² = 2000 · 1,21 = R$ 2.420,00.

Nível difícil

Bases diferentes, decaimento radioativo e troca de variável mais complexa.

PROBLEMA 7

Resolva: 25x = 5x+3

25x = (5²)x = 52x. Então 52x = 5x+3 ⟹ 2x = x+3 ⟹ x = 3.

PROBLEMA 8

Uma substância radioativa tem meia-vida de 8 dias e segue Q(t) = Q0 · (1/2)t/8. Partindo de Q0 = 640 g, quanto restará após 24 dias?

24 ÷ 8 = 3 meias-vidas. Q(24) = 640 · (1/2)³ = 640/8 = 80 g.

PROBLEMA 9

Resolva: 9x − 4·3x − 45 = 0

Fazendo y = 3x: y² − 4y − 45 = 0 ⟹ (y−9)(y+5) = 0 ⟹ y = 9 ou y = −5.

Como y = 3x é sempre positivo, descartamos y = −5. Fica y = 9: 3x = 9 = 3² ⟹ x = 2.
