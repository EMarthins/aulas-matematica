Pergunta

Em qual geração o número de ancestrais chega a 32?

Escrevendo cada geração como potência de base 2:

1ª: 21 · 2ª: 22 · 3ª: 23 · … · x-ésima: 2x

Queremos 2x = 32 = 25, logo x = 5 — a resposta está na 5ª geração.

Essa é exatamente a ideia de uma equação exponencial: a incógnita está no expoente. Vamos formalizar isso.

Aula 69 · Teoria

Equação exponencial

Definição

É toda equação em que a incógnita aparece no expoente de pelo menos uma das potências.

O método

Reduzimos os dois membros a potências de mesma base. Se a base é positiva e diferente de 1:

am = an ⟹ m = n

Exemplo resolvido

2x = 32

32 é potência de base 2? 32 = 2⁵

2x = 25 ⟹ x = 5

S = {5}

Aula 69 · Teoria

Quando as bases não "batem"

Às vezes a equação esconde uma equação do 2º grau. A saída é trocar de variável.

9x − 10 · 3x = −9

1 Note que 9x = (3x)2. Fazendo y = 3x:

y² − 10y + 9 = 0

2 Resolvendo essa equação do 2º grau:

y1 = 9     y2 = 1

3 Voltando à troca (y = 3x) para cada raiz:

3x = 9 = 32 ⟹ x = 2

3x = 1 = 30 ⟹ x = 0

S = {0, 2}

Dica: em todo item, o primeiro passo é escrever os dois lados como potência da mesma base — ou perceber a "cara" de uma equação do 2º grau escondida.

Aula 70 · Teoria

Função exponencial

Bactérias em laticínios se reproduzem tão rápido que o crescimento vira exponencial. Para descrever isso matematicamente, usamos uma função — não apenas uma equação isolada.

Definição

Dado a real, com a > 0 e a ≠ 1, a função f: ℝ → ℝ definida por f(x) = ax, para todo x real, é a função exponencial de base a.

Por que a > 0?

Se a fosse negativo, f(x) = ax deixaria de existir para vários x reais (ex.: (−2)1/2 não é real).

Por que a ≠ 1?

Se a = 1, f(x) = 1x = 1 sempre — vira uma função constante, sem graça exponencial.

Valor numérico de f(x) = 3x:

x−202
f(x)1/919
Atividade 2 · Pratique

É função exponencial?

Clique em cada lei de formação para ver se ela obedece f(x) = ax, com a>0 e a≠1.

Aula 71 · Teoria

O gráfico conta a história

Crescente — a > 1

Ex.: f(x) = 2x

Decrescente — 0 < a < 1

Ex.: f(x) = (1/2)x

Características comuns às duas famílias

Domínio D = ℝ  ·  Imagem Im = ℝ*₊ (só valores positivos)  ·  sempre passa por (0, 1)  ·  nunca toca o eixo x (assíntota y = 0)

Atividade 4 · No ENEM é assim

Depreciação de um automóvel

(ENEM, adaptado) O valor de um carro é dado por f(t) = b·at. No ano 0, vale R$ 60.000; no ano 1, R$ 54.000. Qual o valor ao completar 2 anos de uso?

Passo 1: f(0) = b·a⁰ = b → b = 60.000

Passo 2: f(1) = 60.000·a = 54.000 → a = 0,9

Passo 3: f(2) = 60.000 · (0,9)² = 60.000 · 0,81

f(2) = R$ 48.600,00
