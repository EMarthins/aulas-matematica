Explore o gráfico e monte os pares

Primeiro brinque com o controle deslizante para ver como a base a muda o gráfico de f(x) = logax. Depois, jogue o desafio de encaixe: uma equação logarítmica só "acopla" com a peça certa.

Parte 1 · Controle a base

Arraste o controle para mudar o valor de a em f(x) = logax e observe o gráfico ao lado reagir em tempo real.

Crescente (a > 1)

Quando x aumenta, y também aumenta. Todo gráfico passa pelo ponto (1, 0), porque loga1 = 0 para qualquer base.

Desafio de leitura

Ajuste o slider até deixar a ≈ 0,5 e observe: o que acontece com y quando x se aproxima de 0? E quando x cresce muito?

Dica: perto de x = 0 a curva "dispara" para o infinito (positivo se a<1, negativo se a>1) — é por isso que x = 0 nunca pode entrar no domínio.

Domínio: x > 0 Passa por (1, 0) crescente
