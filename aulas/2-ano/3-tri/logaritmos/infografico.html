Aula 75

Definição

O logaritmo é o expoente ao qual se eleva a base para obter o logaritmando.

loga b = x ⟺ ax = b

Condição de existência

a > 0 e a ≠ 1  (base)  ·  b > 0  (logaritmando)

Aulas 76 e 77

5 consequências da definição

Simplificam contas sem precisar voltar à definição toda vez.

1ªloga 1 = 0
2ªloga a = 1
3ªloga am = m
4ªaloga b = b
5ªloga b = loga c ⟺ b = c

Aula 85

Equação logarítmica

A incógnita aparece dentro de um logaritmo.

  1. Verifique a condição de existência (base e logaritmando > 0).
  2. Aplique as propriedades para reduzir a um único log de cada lado.
  3. Use a 5ª propriedade: logab = logac ⟺ b = c.
  4. Confira se a solução satisfaz a condição de existência.
Aulas 86, 87 e 88

Função logarítmica: f(x) = loga x

É a inversa da função exponencial g(x) = ax. Domínio D = ℝ*₊ (x > 0) · Imagem Im = ℝ.

Crescente — a > 1

Passa por (1, 0). Sobe conforme x cresce.

Decrescente — 0 < a < 1

Passa por (1, 0). Desce conforme x cresce.

  • Sempre passa pelo ponto (1, 0) — pois loga1 = 0
  • Nunca toca o eixo y — assíntota vertical em x = 0
  • É o reflexo de g(x) = ax em torno da reta y = x
