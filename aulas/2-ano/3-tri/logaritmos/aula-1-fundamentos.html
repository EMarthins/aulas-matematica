Para início de conversa

Como medir um terremoto?

Em abril de 2026, um tremor de magnitude 2,4 foi registrado no litoral do Paraná. Sismógrafos medem a amplitude do abalo, e a escala Richter converte isso em magnitude com a fórmula:

M = log A − log A0

M: magnitude · A: amplitude medida · A₀: amplitude de referência

O problema de sempre

Já sabemos resolver 3x = 243 (x = 5, pois 3⁵ = 243). Mas e 2x = 5? Nenhum expoente inteiro resolve isso.

Criamos um nome para esse expoente "escondido": x = log₂ 5.

O logaritmo não elimina o problema — ele dá nome à resposta, assim como usamos √2 para um número que não é uma fração exata.

Aula 75 · Teoria

Definição de logaritmo

Definição

Dados a e b reais positivos, com a ≠ 1: o logaritmo de b na base a é o número x tal que ax = b.

loga b = x ⟺ ax = b

Vocabulário
abase
blogaritmando
xlogaritmo (o resultado)
Exemplo

log2 8 = x ⟺ 2x = 8

2³ = 8, logo x = 3.

Aula 76 · Teoria

Três consequências diretas

Toda medida em decibéis (dB) usa log de base 10 — e essas três regrinhas aparecem o tempo todo.

1ª propriedade

loga 1 = 0

a⁰ = 1 sempre.

2ª propriedade

loga a = 1

a¹ = a sempre.

3ª propriedade

loga am = m

aplicação direta da definição.

Por que isso importa

Um som de 80 dB é 10⁸ vezes mais intenso que o limiar audível — e calcular isso à mão, sem essas propriedades, seria bem mais difícil.

Aula 77 · Teoria

Mais duas ferramentas

O pH de uma solução também usa logaritmo — e essas duas propriedades ajudam a manipular expressões inteiras.

4ª propriedade

aloga b = b

Substituindo x por logab em ax=b.

5ª propriedade

loga b = loga c ⟺ b = c

Mesma base, mesmo logaritmo → mesmo logaritmando.

Combinando tudo — calcule a expressão:

log2 2⁵ + log7 1 + 3log3 2

log₂2⁵ = 5 (3ª prop.)  ·  log₇1 = 0 (1ª prop.)  ·  3log₃2 = 2 (4ª prop.)

5 + 0 + 2 = 7

Atividade 3 · No quadro, oral

Qual propriedade usar?

Peça para identificar, em voz alta, qual das 5 propriedades resolve cada termo antes de somar tudo.

log5 1 + log3 34 + 2log2 6

log₅1 = 0 (1ª)  ·  log₃3⁴ = 4 (3ª)  ·  2log₂6 = 6 (4ª)

0 + 4 + 6 = 10

Em uma expressão logarítmica, cada termo se resolve separadamente antes de somar.

Aula 79 · Teoria

Quando um log deixa de existir

Como num videogame com áreas bloqueadas no mapa, há valores que travam o cálculo do logaritmo.

Logaritmando negativo

log₂(−8) = x → 2ˣ = −8. Nenhuma base positiva dá negativo.

Base igual a 1

log₁2 = x → 1ˣ = 2. 1 elevado a qualquer x é sempre 1.

Base negativa

Impede construir o gráfico da função para todo x real.

Condição de existência

loga b só existe se a > 0, a ≠ 1 e b > 0.

Exemplo: logx(5x+6) = 2 → x² = 5x+6 → x₁=6, x₂=−1.

x = −1 tornaria a base negativa — inválido. Só x = 6 satisfaz base > 0 e logaritmando > 0.

Atividade 5 · No ENEM é assim (ENEM 2019)

A hortênsia cor-de-rosa

O pH de um solo é dado por pH = −log x, sendo x a concentração de H⁺. Uma hortênsia rosa valorizada precisa de solo com 7 < pH < 8. Em qual intervalo deve estar x?

Para pH = 8: 8 = −log x → log x = −8 → x = 10⁻⁸

Para pH = 7: 7 = −log x → log x = −7 → x = 10⁻⁷

Como pH e x variam em sentidos opostos, pH entre 7 e 8 corresponde a x entre 10⁻⁸ e 10⁻⁷.
