Custos em progressão

6 problemas de custo, do mais simples ao mais desafiador. Resolva no papel, digite a resposta e confira — cada um tem uma resolução completa esperando por você.

Acertos: 0/6
NÍVEL 1

Uma barraca de tapioca tem custo fixo de R$ 150,00/mês e custo variável de R$ 3,00 por tapioca. Qual é o custo total para produzir 60 tapiocas em um mês?

R$

C(x) = CF + CV·x = 150 + 3×60 = 150 + 180 = R$ 330,00.

NÍVEL 1

Uma pequena fábrica registrou: produzir 20 unidades custou R$ 500,00 no total; produzir 35 unidades custou R$ 800,00 no total. Qual é o custo variável por unidade?

R$

Variação de custo: 800 − 500 = 300. Variação de quantidade: 35 − 20 = 15. Custo variável = 300 ÷ 15 = R$ 20,00 por unidade.

NÍVEL 2

Usando os dados do problema anterior (20 unidades custam R$ 500,00; custo variável de R$ 20,00/unidade), qual é o custo fixo dessa fábrica?

R$

C(x) = CF + CV·x → 500 = CF + 20×20 → 500 = CF + 400 → CF = R$ 100,00.

NÍVEL 2

Uma loja tem custo fixo de R$ 900,00/mês, custo variável de R$ 25,00 por unidade e vende cada unidade por R$ 70,00. Qual é a quantidade mínima de vendas (ponto de equilíbrio, arredondado para cima) para a loja não ter prejuízo?

unidades:

Ponto de equilíbrio: CF ÷ (PV − CV) = 900 ÷ (70 − 25) = 900 ÷ 45 = 20 unidades.

NÍVEL 3

Com os mesmos dados da loja anterior (CF = R$ 900,00, CV = R$ 25,00, PV = R$ 70,00), qual é o lucro se ela vender 50 unidades no mês?

R$

Receita: 50×70 = 3.500. Custo: 900 + 25×50 = 900 + 1.250 = 2.150. Lucro = Receita − Custo = 3.500 − 2.150 = R$ 1.350,00.

NÍVEL 3

Um produto custa R$ 80,00 para ser fabricado. A empresa quer obter um lucro de 35% sobre o custo em cada unidade vendida. Qual deve ser o preço de venda?

R$

Lucro por unidade: 80 × 0,35 = 28. Preço de venda = custo + lucro = 80 + 28 = R$ 108,00 (o mesmo que 80 × 1,35).
