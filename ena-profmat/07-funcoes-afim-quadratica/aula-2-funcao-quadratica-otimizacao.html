Objetivos da aula

O que você vai saber fazer

  • Calcular vértice, raízes, interseção com os eixos e concavidade de y = ax2 + bx + c.
  • Escrever a lei de uma parábola a partir das raízes e de um ponto.
  • Achar mínimos e máximos, inclusive restritos aos inteiros.
  • Resolver reta × parábola e ler gráficos para descobrir as expressões.

Em prova

Quadrática no ENA quase sempre é: f(0) = c, vértice ou Δ = 0 (tangência). Tenha a ficha na ponta da língua.

Para início de conversa

O menor valor de x² − 6x + 5

Em vez de tentar valores, use o vértice: o ponto mais baixo (ou alto) da parábola.

O vértice de f(x) = x2 − 6x + 5 é:

xv = −b2a = 62 = 3 e yv = f(3) = 9 − 18 + 5 = −4. Como a > 0, é um mínimo: o valor mínimo é −4.

Ideia-chave

O vértice é o ponto médio das raízes e fica sobre o eixo de simetria x = xv. Ele responde “qual o maior (ou menor) valor?”.

Teoria · ficha da parábola

Tudo sobre y = ax² + bx + c

  • c = f(0): ordenada onde corta o eixo y. f(1) = a + b + c · f(−1) = a − b + c.
  • a > 0: concavidade para cima (mínimo); a < 0: para baixo (máximo).
  • Δ = b2 − 4ac define quantas raízes reais: Δ > 0 (2), Δ = 0 (1), Δ < 0 (0).
  • Vértice: xv = −b2a (média das raízes), yv = −Δ4a = f(xv).
  • Formas: canônica a(x − xv)2 + yv; fatorada a(x − x1)(x − x2). S = −b/a, P = c/a.

Explorador da parábola

Lei da parábola

Raízes + um ponto determinam a lei

Se as raízes são r e s, então f(x) = a(x − r)(x − s). Um ponto qualquer fixa o valor de a.

Treino 7.6

Raízes −1 e 3, passa por (0, −3): f(0) = a(1)(−3) = −3a = −3 ⇒ a = 1. Então f(x) = x2 − 2x − 3.

A parábola que passa por (2, 6)

A parábola y = ax2 + bx + c passa pelo ponto (2, 6). A ordenada do ponto onde ela corta o eixo vertical é 2. Qual o valor de 2a + b + c?

Escolha a alternativa:

c = f(0) = 2. f(2) = 4a + 2b + c = 6 ⇒ 4a + 2b = 4 ⇒ 2a + b = 2. Então 2a + b + c = 2 + 2 = 4. Alternativa C.

Reta × parábola

Iguale as expressões: o Δ responde

Igualando f(x) = g(x) obtemos uma equação do 2º grau: Δ > 0 → dois pontos; Δ = 0 → um único ponto (tangência); Δ < 0 → nenhum.

y = x² − 1 e y = mx − 4

ENA 2026 Q14

x2 − 1 = mx − 4 ⇒ x2 − mx + 3 = 0; ponto único ⇒ Δ = m2 − 12 = 0 ⇒ m = 2√3 (com m > 0). A reta y = 2√3·x − 4 corta o eixo x em x = 42√3 = 2√33.

Tangência e raiz de g

Os gráficos de f(x) = x2 − 1 e g(x) = mx − 4, com m > 0, intersectam-se em um único ponto. Em que x o gráfico de g corta o eixo das abscissas?

Escolha a alternativa:

x2 − 1 = mx − 4 ⇒ x2 − mx + 3 = 0; ponto único ⇒ Δ = m2 − 12 = 0 ⇒ m = 2√3. g(x) = 0 ⇒ x = 4m = 42√3 = 2√33. Alternativa D.

Leitura de gráfico: reta e parábola

Reta crescente e parábola com concavidade para baixo e uma raiz positiva se cortam em (−4, 0) e (0, 4). Quais as expressões da parábola e da reta? (alternativas de treino)

Escolha a alternativa:

A reta por (−4, 0) e (0, 4) é y = x + 4 (crescente ✓). Iguale: −x2 − 3x + 4 = x + 4 ⇒ x2 + 4x = 0 ⇒ x = 0 ou x = −4 ✓. A parábola −(x + 4)(x − 1) tem raízes −4 e 1 (uma positiva) e concavidade para baixo ✓. Alternativa E.

Otimização

Problemas clássicos de máximo e mínimo

  • Soma fixa x + y = S → produto xy máximo quando x = y = S/2.
  • Perímetro fixo → a maior área do retângulo é a do quadrado.
  • Qualquer “lucro/área/altura” quadrática: vértice.
  • Triângulo retângulo inscrito em círculo de raio r: área máxima r2 (capítulo 12).

Treino 7.3

Dois números somam 20: x(20 − x) é máximo em x = 10 → 100.
