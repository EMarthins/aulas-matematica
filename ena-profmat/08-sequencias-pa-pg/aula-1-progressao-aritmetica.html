Objetivos da aula

O que você vai saber fazer

  • Usar an = a1 + (n − 1)r e Sn = n(a1 + an)2 em problemas de texto.
  • Reconhecer a PA escondida numa soma Sn = An2 + Bn.
  • Calcular somas notáveis de inteiros, ímpares e pares.
  • Aplicar o termo médio e a ideia “três termos em PA”.

Em prova

A pergunta “qual o décimo termo?” quando dão a soma dos termos é quase sempre an = Sn − Sn−1.

Para início de conversa

A soma de 1 a 100 em segundos

Diz a lenda que o menino Gauss somou 1 + 2 + ⋯ + 100 em segundos: pareou o primeiro com o último, o segundo com o penúltimo, e assim por diante.

Quanto vale 1 + 2 + 3 + ⋯ + 100?

Há 50 pares e cada par soma 101: 50 · 101 = 5050. É a fórmula n(a1 + an)2 = 100 · 1012.

Ideia-chave

Em uma PA, os termos equidistantes dos extremos somam o mesmo valor: a1 + an = a2 + an−1 = ⋯. Daí vem Sn.

Teoria · PA

Termo geral, soma e termo médio

an = a1 + (n − 1)r   am = an + (m − n)r

Sn = (a1 + an)·n2 = n[2a1 + (n − 1)r]2

Termo médio

b = a + c2 quando a, b, c estão em PA. Três termos em PA: x − r, x, x + r.

Truque · de Sₙ para aₙ

Dada a soma dos n primeiros termos, ache o termo

O termo é a diferença de duas somas consecutivas: o que a soma ganhou ao passar de n − 1 para n termos.

a1 = S1   an = Sn − Sn−1 (n ≥ 2)

Caso quadrático

Se Sn = An2 + Bn, a sequência é uma PA com a1 = A + B e razão r = 2A; an = A(2n − 1) + B.

O décimo termo de uma sequência

A soma dos n primeiros termos de uma sequência é Sn = 3n2 + 4n. Qual é o décimo termo?

Escolha a alternativa:

a10 = S10 − S9 = (300 + 40) − (243 + 36) = 340 − 279 = 61. Pela fórmula an = 6n + 1: a10 = 61. Alternativa A. (340 é a soma dos 10 primeiros, não o décimo termo.)

Geometria + PA

Triângulo retângulo com lados em PA é 3-4-5

Se os lados estão em PA, escreva x − r, x, x + r. Pitágoras: (x + r)2 = (x − r)2 + x2 ⇒ 4xr = x2 ⇒ x = 4r. Os lados são 3r, 4r, 5r.

Consequência

Os ângulos agudos têm seno e cosseno iguais a 3/5 e 4/5 (ou o contrário). Logo cos α + cos β = 35 + 45 = 75.

Os lados de um triângulo retângulo estão em PA e o maior é 10. O menor lado mede:

Lados 3r, 4r, 5r com 5r = 10 ⇒ r = 2: lados 6, 8, 10. O menor mede 6.

Lados em PA e a soma dos cossenos

Os lados de um triângulo retângulo estão em PA. Se α e β são os ângulos agudos, qual o valor de cos α + cos β?

Escolha a alternativa:

Lados x − r, x, x + r: (x + r)2 = (x − r)2 + x2 ⇒ 4xr = x2 ⇒ x = 4r → lados 3r, 4r, 5r. cos α + cos β = 35 + 45 = 75. Alternativa E.

Cuidado

Onde se perde ponto em PA

Confundir Sn com an

Pedem o termo mas dão a soma: an = Sn − Sn−1. S10 = 340 não é o décimo termo.

Contar mal n

De 3 a 99 de 3 em 3: n = (99 − 3)/3 + 1 = 33, não 32.

Esquecer a1 = S1

A fórmula Sn − Sn−1 só vale a partir de n ≥ 2; o primeiro termo é S1.

Usar r errado

Em Sn = An2 + Bn, a razão é 2A (não A).
