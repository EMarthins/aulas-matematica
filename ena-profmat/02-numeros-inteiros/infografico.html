Aula 1

Divisão euclidiana

n = d·q + r,   0 ≤ r < d

n é múltiplo de d ⇔ r = 0. O resto é sempre menor que o divisor.

Aula 1

Macete dos restos

Se D é múltiplo de d e n = Dq + r, então n e r deixam o mesmo resto por d.

MMC e MDC

MMC: eventos que se repetem. MDC: grupos iguais, maior pedaço.

mmc(a,b) · mdc(a,b) = a · b

Fatoração

MMC: maior expoente · MDC: menor expoente dos fatores comuns.

Armadilhas

O que mais tira ponto

  • Resto ≥ divisor: reduza de novo (220 = 5·41 + 15).
  • Trocar MMC por MDC: repetição → MMC; grupos iguais → MDC.
  • Contar o instante 0 em “quantas vezes mais?” (ENA 2026 Q8: 24 h e 48 h, só 2 vezes).
  • Número de divisores = produto de (expoente + 1), não a soma.
  • Esquecer restrições dos algarismos (a > 4, centenas ≠ 0).
