Dízimas e conjuntos numéricos

Qual é a fração geratriz?

N ⊂ Z ⊂ Q ⊂ R   racional ⇔ decimal finito ou dízima periódica

Geratriz

Padrões: 0,aaa… = a9; 0,ababab… = ab99; 0,abbb… = ab − a90. Ex.: 0,777… = 79; 0,1666… = 16 − 190 = 16. E 0,999… = 1.

Lembre

Soma e produto de racionais são racionais; racional não nulo × irracional é irracional; irracional ± irracional pode ser racional (√2 + (−√2) = 0).

Dízima periódica

Médias e desigualdades

MH ≤ MG ≤ MA e como usar

MH = 2aba + b ≤ MG = √ab ≤ MA = a + b2

Usos

Maximizar produto com soma fixa; minimizar soma com produto fixo: x + 1x ≥ 2 para x > 0. A igualdade só ocorre se a = b.

Técnicas de demonstração

Indução, absurdo, pombos e invariantes

Indução

Prove a base (n = 1) e, supondo para n = k, prove n = k + 1. Ex.: 1 + ⋯ + n = n(n+1)/2.

Absurdo

Suponha o contrário e chegue a uma contradição. Ex.: √2 é irracional.

Casa dos pombos

n + 1 objetos em n caixas ⇒ alguma caixa tem ≥ 2.

Paridade / invariantes

Ache uma grandeza que não muda ao longo do processo.
