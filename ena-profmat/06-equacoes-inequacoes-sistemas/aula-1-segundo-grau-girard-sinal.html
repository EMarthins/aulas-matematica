Teoria · sinal da quadrática

Onde f(x) = ax² + bx + c é positiva?

CasoSinal
a > 0, raízes x1 < x2f > 0 fora das raízes; f < 0 entre elas
a < 0, raízes x1 < x2o contrário
Δ < 0f tem sempre o sinal de a
Δ = 0f tem o sinal de a (exceto na raiz, onde é 0)

Exemplo

x2 + 6x − 16 = (x − 2)(x + 8) < 0 ⇔ −8 < x < 2.

Teoria · inequações de 1º grau

Equivalência de desigualdades (ENA 2025 Q22)

Somar o mesmo número aos dois lados mantém o sentido; multiplicar por positivo mantém; por negativo inverte. Com isso, reescreva a desigualdade até reconhecer a alternativa.

Q22 (2025)

x + y2 > y ⇔ x + y > 2y ⇔ x > y. Em palavras: a média está acima de y ⇔ y é o menor ⇔ a média está abaixo de x: x + y2 < x.

Qual desigualdade é equivalente a x + y2 > y?

x + y2 > y ⇔ x > y. Só a alternativa D diz o mesmo: x + y2 < x ⇔ x + y < 2x ⇔ y < x. Alternativa D.

Teoria · quociente

Inequação-quociente: tabela de sinais

fg > 0 ⇔ f·g > 0 e g ≠ 0. Passe tudo para um lado, ponha sobre denominador comum, fatore e estude o sinal de cada fator numa reta. Para ≥, inclua os zeros de f, nunca os de g.

(x − p) / (x − q) com sinal escolhido

Nunca faça isto

Multiplicar “em cruz” x − 1x + 2 < x ⇒ x − 1 < x(x + 2) sem saber o sinal de x + 2: se x + 2 < 0 a desigualdade inverte. Passe x para o outro lado e compare com zero.

Resolver sem necessidade

Pediram soma/produto/soma dos quadrados? Use Girard. Só confirme que Δ > 0 e que as raízes valem no problema.

Esquecer o sentido da parábola

Com a < 0, f > 0 entre as raízes. Olhe o sinal de a antes de ler o intervalo.

Multiplicar por expressão de sinal desconhecido

Em quocientes, passe tudo para um lado e use tabela de sinais; nunca “em cruz”.

Contar mal os inteiros

Em −8 < x < 2 não entram −8 nem 2: de −7 a 1 são 9 inteiros.

Δ e raízes
