Para início de conversa

A raiz que não vale

Resolva √x + 3 = x − 3. Elevando ao quadrado: x + 3 = x2 − 6x + 9, ou x2 − 7x + 6 = 0, de raízes x = 1 e x = 6. As duas servem?

Quais valores são solução da equação original?

Teste: x = 1: √4 = 2, mas 1 − 3 = −2 ✗ (raiz estranha). x = 6: √9 = 3 = 6 − 3 ✓. Elevar ao quadrado “perde” o sinal e cria raízes que não valem.

Ideia-chave

Toda operação que não é reversível (elevar ao quadrado, multiplicar por expressão com x) pode criar raízes estranhas. Sempre confira no enunciado.

Inequação-quociente equivalente

Qual alternativa é equivalente a x − 1x + 2 < x? (A) x + 2 > 0 (B) x + 1 > 0 (C) x − 2 > 0 (D) x − 3 > 0 (E) x − 4 > 0

Escolha a alternativa:

x − 1x + 2 − x < 0 ⇔ x − 1 − x2 − 2xx + 2 < 0 ⇔ −x2 − x − 1x + 2 < 0 ⇔ x2 + x + 1x + 2 > 0. Como x2 + x + 1 > 0 sempre (Δ = −3), o sinal é o de x + 2: x + 2 > 0 — alternativa A.

Fatoração

x3 − x = 0 ⇒ x(x − 1)(x + 1) = 0 ⇒ x = 0, 1, −1. Produto nulo: um fator zero.

Tangência

Reta e parábola com um único ponto comum: Δ = 0 ao igualar. Treino 6.5: x2 + kx + 9 com raiz dupla → k2 − 36 = 0 ⇒ k = ±6.

Sistemas lineares 2×2: adição, substituição e Cramer

Para a1x + b1y = c1 e a2x + b2y = c2: D = a1b2 − a2b1, Dx = c1b2 − c2b1, Dy = a1c2 − a2c1.

Esquecer a condição de existência

Equação fracionária: x ≠ −3, 1. Uma raiz que zera um denominador deve ser descartada.

Não testar a raiz estranha

Elevar ao quadrado cria raízes. Em √x + 3 = x − 3, x = 1 não vale: o lado direito é negativo.

Modular sem a condição g ≥ 0

∣f∣ = g exige g ≥ 0. Valores que dão g < 0 não servem.
