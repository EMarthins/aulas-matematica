Para início de conversa

Cada conjunto nasceu de uma necessidade

N — naturais

0, 1, 2, 3, … Contar. Falta: 3 − 5.

Z — inteiros

… −2, −1, 0, 1, 2 … Subtrair sempre. Falta: 1 ÷ 3.

Q — racionais

pq com p, q ∈ Z, q ≠ 0. Dividir sempre. Falta: √2.

R — reais

Racionais e irracionais (I). Completa a reta: cada ponto é um número.

Qual cadeia de inclusões está correta?

Todo natural é inteiro, todo inteiro é racional (n = n/1) e todo racional é real: N ⊂ Z ⊂ Q ⊂ R. Os irracionais I são os reais que não são racionais: R = Q ∪ I.

Teoria · racionais

Fração, decimal finito e dízima periódica

Todo racional tem representação decimal finita ou periódica — e vice-versa. A fração que gera a dízima é a geratriz:

0,aaa… = a9   0,ababab… = ab99   0,abbb… = ab − a90

Exemplos

0,777… = 79 · 0,36… = 3699 = 411 · 0,1666… = 16 − 190 = 16 · 0,999… = 1.

Quando é decimal finito?

A fração irredutível p/q dá decimal finito se, e só se, q tem apenas os fatores 2 e 5 (ex.: 3/8 = 0,375; 1/6 = 0,1666…).

Teoria · irracionais

√2 não é fração: a prova por absurdo

Suponha √2 = pq com p, q inteiros e a fração irredutível. Então p2 = 2q2.

1
p2 é par, logo p é par: p = 2k.
2
Então 4k2 = 2q2, isto é, q2 = 2k2: q também é par.
3
p e q pares contradizem “fração irredutível”. Absurdo! Logo √2 ∉ Q.

Irracionais comuns

√n com n não quadrado perfeito, π, e, e decimais infinitos sem período (ex.: 0,1010010001…). Soma/produto de racionais é racional; racional não nulo × irracional é irracional; irracional ± irracional pode ser racional (√2 + (−√2) = 0).

Operações

Frações: somar, multiplicar, dividir

ab ± cd = ad ± bcbd   ab·cd = acbd   ab ÷ cd = adbc

Dica

Para somar, use o MMC dos denominadores (menos contas). Simplifique antes de multiplicar. Dividir por uma fração é multiplicar pelo inverso.

Comparando

Qual é maior? Elevar ao quadrado e aproximar

  • Números positivos: x < y ⇔ x2 < y2. Compare os quadrados: 3√2 × 2√3 → 18 × 12 → 3√2 é maior.
  • Entre dois inteiros: n2 ≤ m < (n+1)2 ⇒ n ≤ √m < n + 1. Ex.: 49 < 50 < 64 ⇒ 7 < √50 < 8.
  • Frações: reduza ao mesmo denominador ou compare produtos em cruz (a/b < c/d ⇔ ad < bc, com b, d > 0).
  • √a + √b ≠ √a+b: compare (√a + √b)2 = a + b + 2√ab com a + b.

Onde se perde ponto com conjuntos numéricos

Achar que toda raiz é irracional

√16 = 4 e √0,25 = 0,5 são racionais. Só √n com n não quadrado perfeito (e racionais não quadrados) é irracional.

Dízima × decimal infinito

Decimal infinito periódico é racional; infinito sem período é irracional.

Geratriz com antiperíodo

0,1666… é 16 − 190, não 1699.
